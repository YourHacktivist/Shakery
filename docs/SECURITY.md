# Sécurité

Ce document suit la section 6 de `docs/SPEC.md` point par point : ce qui est en place, le fichier qui l'implémente et le test qui le vérifie. Il sert de checklist de relecture en phase 11.

Lancer les vérifications :

- tests unitaires : `npm test` (`src/main/security-policy.test.ts`, `src/main/ipc/dispatch.test.ts`) ;
- tests de bout en bout sur l'application construite : `npm run test:e2e` (`tests/e2e/security.spec.ts`, `tests/e2e/app.spec.ts`).

Légende du statut : **fait**, **partiel** (une partie est en place), **sans objet** (la fonction concernée n'existe pas encore). Checklist relue point par point contre le code le 22 novembre 2026 (phase 11).

## Mesures en plus de la spec

- `<webview>` refusé à l'attachement (`will-attach-webview`) et téléchargements refusés (`will-download`), dans `src/main/security.ts`.
- En-tête `X-Content-Type-Options: nosniff` sur les réponses et sur le protocole média.
- Instance unique (`requestSingleInstanceLock`) dans `src/main/index.ts`, vérifiée par l'e2e « a second instance on the same data exits and leaves the first one alone ».
- Menu applicatif supprimé (D-010).
- Le dossier de données ne peut être remplacé par variable d'environnement que hors build packagé (D-012).
- Export (phase 10) : chaque fichier est écrit à l'emplacement choisi dans la boîte d'enregistrement du main, jamais à un chemin venu du renderer ; nom proposé nettoyé des caractères refusés par Windows ; une image envoyée par le renderer doit porter la signature PNG et rester sous 10 Mo (`src/main/ipc/share.ts`).
- CSV : une cellule qui commence par `=`, `+`, `-` ou `@` est préfixée d'une apostrophe, pour qu'un tableur ne l'exécute jamais comme une formule (`src/main/services/csv.ts`, testé).
- Presse-papiers : la copie d'une fiche passe par le main (`export.copyText`), la session gardant toutes les permissions refusées au renderer.
- Export partiel : un lien vers ce qui n'est pas exporté (fiche parente, bouteille préférée, guide de référence) est vidé, et les données personnelles (dégustations, carnet, prix des bouteilles) ne partent que sur demande explicite.
- Journal local sans donnée personnelle : identifiants, codes et origines d'URL. Les chemins que portent les erreurs du système de fichiers sont retirés avant écriture et le dossier personnel devient `~` (`redactPaths`, testé).
- Dossier de sauvegarde : seul le main peut le changer, par sa boîte de choix de dossier ; `settings.set` ne l'accepte pas.
- Réglages : liste fermée de clés modifiables par le renderer, chacune validée par son schéma.
- Barre de titre masquée : les boutons de la fenêtre restent natifs, la page ne les dessine pas.
